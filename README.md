# CHAT MALI 🇲🇱🤖

> **« Ton ami IA, dans ta langue. »**  
> *« An ka kuma. An ka dɔgɔya. »*

CHAT MALI est un compagnon IA conversationnel conçu pour être comme un véritable ami numérique de l’utilisateur. Il associe la chaleur culturelle malienne, la richesse de la langue **Bambara (Bamanankan)** et la puissance des technologies d’intelligence artificielle multilingues.

---

## 🌟 Fonctionnalités Clés

- **🇲🇱 Mode Bambara natif** : L’application et l’IA s’expriment couramment en Bambara, traduisent les expressions et favorisent une formulation naturelle.
- **🎙️ Conversation Vocale Live (« 🎧 Conversation Live »)** : Expérience vocale continue avec onde sonore animée, reconnaissance vocale et réponse par synthèse vocale.
- **🔊 10 Voix Maliennes Authentiques** :
  - *Féminines* : Awa (Douce), Fatou (Naturelle), Mariam (Calme), Aminata (Énergique), Nènè (Amicale).
  - *Masculines* : Amadou (Profonde), Moussa (Naturelle), Bakary (Chaleureuse), Oumar (Calme), Sékou (Dynamique).
- **🌍 Outil Traducteur Intégré** : Traduction instantanée Bambara ↔ Français avec prononciation audio et répertoire d’expressions courantes.
- **⚡ Modes Spécialisés** : Ami (🤝), Études (📚), Travail (💼), Business (💰), Traduction (🌍), Rédaction (✍️), Programmation (💻), Créativité (🎨), Coach (🧠).
- **🛠️ Barre d’Outils Intelligente par Message** :
  - 🔊 Lire à voix haute
  - 🌍 Traduire
  - ✂️ Réponse plus courte
  - 💡 Expliquer simplement
  - 📋 Copier le texte
  - 🔄 Régénérer la réponse
- **🧠 Mémoire Personnalisée** : Retient le prénom de l’utilisateur, sa langue de prédilection et ses préférences.
- **📱 Design Mobile-First & Identité Malienne** : Palette vert profond, or et rouge carmin, animations fluides et typographie premium.

## 🚀 Technologies Utilisées

| Composant | Technologie |
|---|---|
| **Framework** | TanStack Start (React 19, Vite 7) |
| **Routing** | TanStack Router v1 (file-based) |
| **Styling** | Tailwind CSS v4 avec tokens personnalisés Mali |
| **Icônes** | Lucide React |
| **Voix & Audio** | Web Speech API (SpeechRecognition + SpeechSynthesis) |
| **Déploiement** | Netlify |
